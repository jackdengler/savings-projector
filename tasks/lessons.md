# Lessons

## "Could we improve this?" means product, not polish (2026-09-29)

**What happened:** Asked an open-ended "could we improve this?", I audited the
code, fixed bugs and listed small modeling gaps. The user redirected: "think
differently."

**Rule:** For open-ended improvement questions, lead with the product level: what
decision is the user really trying to make, and does the tool answer it? Ideas
like reframing the model, changing the workflow, or adding new capabilities go
first. Code-quality fixes are a secondary tier. Mention them briefly and fix them
quietly, but don't make them the answer.
